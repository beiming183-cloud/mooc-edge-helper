# 中国大学 MOOC 资料助手（Edge）

这是一个面向 **Microsoft Edge** 的中国大学 MOOC（icourse163.org）课程资料提取扩展。

当前版本为 **v1.0.0 正式版**。它会利用你已经登录的 Edge 会话，扫描当前有权限访问的课程页面，识别课程中的文档、课件和附件，并尽量获取平台实际提供的原始文件下载地址。v1.0.0 已完成真实课程验证：在“材料工程基础”课程中成功识别 5 章、43 个文档/附件单元，43 个下载链接全部解析成功，未解析 0 个。

## 主要功能

- 自动识别当前课程和 `termId`
- 读取课程章节、课时和资源结构
- 识别文档与附件资源
- 优先获取平台提供的原始文档地址
- 支持识别 PPT/PPTX、PDF、Word、Excel、CSV、ZIP 等常见文件
- 按“课程 → 章节 → 课时”自动整理下载目录
- 提供“复制诊断”，方便接口变化后继续适配
- 使用 Edge 当前登录状态，不需要在扩展中保存账号和密码

下载后的目录大致如下：

```text
下载/
└─ 中国大学MOOC/
   └─ 课程名称/
      ├─ 01_第一章/
      │  ├─ 01.01_第一节/
      │  │  ├─ 课件.pptx
      │  │  └─ 讲义.pdf
      │  └─ ...
      └─ ...
```

## 安装方法

1. 点击仓库右上方 **Code → Download ZIP** 下载源码。
2. 解压到一个固定文件夹。
3. 在 Edge 地址栏打开：

   `edge://extensions/`

4. 打开右侧的“开发人员模式”。
5. 点击“加载解压缩的扩展”。
6. 选择本项目文件夹。
7. 在 Edge 中登录中国大学 MOOC。
8. 打开需要提取资料的课程学习页。
9. 点击 Edge 工具栏里的“MOOC 资料助手”。
10. 点击“扫描当前课程”。

课程学习页一般类似：

```text
https://www.icourse163.org/learn/学校-课程ID?tid=学期ID#/learn/announce
```

## 测试时重点关注

扫描后主要看三个数字：

- 章节数
- 识别到的文档/附件单元数
- 成功解析到下载链接的数量

如果能识别课程，但“未解析”数量较多，请点击 **复制诊断**，把诊断 JSON 提交到 Issue。诊断信息不会主动包含账号密码，也不会输出登录 Cookie。

如果提示课程结构接口失败，请先确认：

- 当前 Edge 已登录中国大学 MOOC；
- 当前页面属于 `/learn/` 或 `/spoc/learn/`；
- 刷新课程页后重新扫描。

## 当前限制

- v1.0.0 已通过真实课程环境测试；不同课程、SPOC 或特殊附件类型仍可能需要后续适配。
- 目前一次只扫描一门课程。
- 暂不处理视频下载。
- 如果平台只提供在线预览而没有暴露原始 PPTX，扩展只能获取平台实际提供的 PDF 或预览文件。
- 只处理当前账号本来就有权限访问的资源，不绕过课程权限、付费限制或 DRM。
- 中国大学 MOOC 的内部接口和字段可能发生变化，因此后续版本会继续增强兼容性。

## 实现思路

当前版本采用“课程接口读取 + 文档接口解析”的方式，而不是单纯扫描网页 DOM。

主要参考了以下公开项目中的接口结构和兼容思路：

- [furina061006/MOOC_reminder](https://github.com/furina061006/MOOC_reminder)：用于参考 Chromium 扩展中的课程结构读取、登录会话和接口兼容方式。
- [MoocDownloader/MoocDownloader](https://github.com/MoocDownloader/MoocDownloader)：用于参考中国大学 MOOC 文档资源类型及原始文档地址解析方式。

本项目代码为重新实现，没有直接复制上述项目的大段源码。
